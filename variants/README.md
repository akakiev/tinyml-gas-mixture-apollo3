# Варіанти моделі для прошивки

| Папка | Модель | Для чого |
|---|---|---|
| `qat_int8/` | int8 QAT DS-1D-CNN **зі статті** (60,0 % на тесті етилен+CO, 14 360 Б) | рядки «int8 QAT, CMSIS-NN, 48 / 96 MHz» + перевірка збігу з ПК |
| `float32/` | float32 DS-1D-CNN тієї ж архітектури з іншого прогону навчання (22 396 Б) | **лише вартість** (Flash, арена, затримка, енергія) для рядка «float32, no CMSIS-NN» |

Перемикання: `python3 python/use_variant.py qat_int8` або `float32` (копіює `model_data.cc`,
`model_config.h` у `firmware/src/` і `hil_test.npz` у `results/`).

Не запускайте `export_firmware.py --variant qat_int8`: файл `results/ds_cnn_qat_int8.tflite` у
попередньому архіві був з іншого прогону (52,6 %), а не з моделі статті (60,0 %).
Точність float32-варіанта з плати в статтю не пишіть: вона не відповідає float32-моделі з табл. 2.
Затримка й енергія від значень ваг не залежать, тому для рядка вартості float32 цей файл коректний.
